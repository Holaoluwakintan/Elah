ELAH WARRIOR · NARRATOR SCRIPT

For Michael to record in his own voice. One audio file per card.

How to add a recording:
  1. Record the card's words (the line in quotes, then the reference, if you like) as an MP3.
  2. Name the file exactly as shown after FILE: (for example moses-your-advisor_xxxxx.mp3).
  3. Put it in the game folder audio/narration/ and add its name to audio/narration/manifest.json under "files".
  4. Players hear it when the card opens (Settings › Narrator: ON). Cards with no file stay silent.

Scripture is the King James Version, exactly as it appears in the game. The "Read" text is the card as shown on screen.
Each file name is tied to that card's words: if a card's wording ever changes, its file name changes too (Tab will update this script).
